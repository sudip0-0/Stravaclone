## Evidence classification

- **Static evidence** checks that required React Native semantics and layout constraints remain wired in source. It does not measure native rendering or focus behavior.
- **Model evidence** exercises deterministic assumptions: the 320dp calendar viewport reserves seven fixed 48dp columns and scrolls horizontally; the attribution model uses a 320dp container and 2× font scale to verify wrapping and 48dp link targets. It is not a native font measurement.
- **Physical evidence** must verify rendered bounds, clipping, wrapping, HUD separation, focus order/retention, and link activation with supported iOS/Android screen readers and maximum platform text/display sizes. That evidence remains blocked below.

## Release evidence required

For each blocked row, record device model, OS version, app/build identifier, locale, unit preference, text scale, assistive technology, result, defects, and a screenshot or screen recording where privacy permits. Never capture real GPS tracks, account credentials, tokens, or private photos in evidence.
